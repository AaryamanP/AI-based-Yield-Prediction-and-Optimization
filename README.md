# High-Accuracy Crop Yield Prediction Model

This project contains a Jupyter Notebook (`yield_prediction.ipynb`) that builds and evaluates a machine learning model to predict crop yield with over 96% R-squared accuracy. It uses a rich dataset including weather, fertilizer, soil, and seasonal data to train high-performance gradient boosting models.

## Project Goal

The primary objective was to develop a model that could explain at least 95% of the variance in crop yield (R² > 0.95). The final LightGBM model successfully achieved an R² of **96.6%**.
